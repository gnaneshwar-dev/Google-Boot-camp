## Brand & Style

This design system channels a Retro-Modern Dev Arcade aesthetic. It merges high-energy arcade nostalgia with precision developer utility, evoking excitement, focus, and technical dominance. 

### Brand Personality & Emotional Response
- **Persona:** Energetic, precise, rebellious, and deeply technical.
- **Emotional Response:** High-octane engagement balanced with absolute clarity. It should feel like stepping into a high-performance terminal built for speed and execution.

### Design Style
The visual language is a hybrid of **Retro / Vaporwave** and **Minimalism**: dark, immersive atmospheres anchored by crisp neon accents, high-contrast states, and razor-sharp structural layouts.

## Colors

The palette is engineered for low-light developer environments, utilizing deep midnight foundations contrasted with hyper-vibrant neon signals.

- **Primary (`#00F5D4` - Neon Cyan):** Core interactive states, active links, and primary actions.
- **Secondary (`#FF2A85` - Electric Magenta):** High-impact highlights, critical badges, and hero elements.
- **Tertiary (`#FFB703` - Warning Amber):** Secondary alerts, performance warnings, and auxiliary indicators.
- **Success (`#38B000`):** Build passes, operational statuses, and positive confirmations.
- **Critical (`#EF233C`):** System failures, errors, and destructive actions.
- **Neutral Base (`#0B0F19` - Deep Midnight):** Canvas background.
- **Surface Elevation (`#141B2D`):** Card and container backgrounds.

## Typography

Typography balances clean geometric readability with dense, utilitarian monospace data streams. 

### Scaling Guidelines
- Headlines larger than 32px must scale down on viewports smaller than 768px to prevent wrapping anomalies.
- Monospace tokens (`code-md`, `code-sm`) are strictly reserved for latency metrics, console logs, system outputs, and hexadecimal hash displays. Ensure these elements maintain rigid horizontal alignment.

## Layout & Spacing

The layout relies on a **12-column fluid grid** system optimized for high-density dashboard layouts, monitoring tools, and arcade-style telemetry views.

### Breakpoints & Adaptability
- **Mobile (< 768px):** Single-column reflow, stacked telemetry cards, persistent bottom navigation.
- **Tablet (768px - 1200px):** 6-column collapsible sidebar layout, compact spacing rhythm.
